# LedgerForge

Sistema de ledger com partida dobrada e pagamentos idempotentes.

## Funcionalidades planejadas
- Criar e gerenciar contas
- Registrar lançamentos em partida dobrada
- Transferir valor entre contas
- Webhooks para notificação de transferências

## Stack
- Java 21 + Spring Boot
- TypeScript + Node.js (notificações)
- PostgreSQL
- Redis
- RabbitMQ

## Como rodar (em breve)
docker compose up --build
